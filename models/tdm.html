Travel Demand Model

The Wasatch Front Travel Demand Model forecasts travel on the region’s roads and transit. WFRC and MAG develop it together.

The WF TDM is a regional model of how people travel. Planners use it to test transportation investments and policies, and to support the Regional Transportation Plan. WFRC and the Mountainland Association of Governments (MAG) develop and maintain it together.

Getting the model

Model files are shared by request through a private GitHub repository, after you read the release letter and talk to WFRC or MAG staff about your planned use. The Get the model guide walks through it step by step.

Reproducible runs and calibration

Two repositories apply the model in a traceable, repeatable way:

  • TDM run results publishes experiment results, such as sensitivity tests, project alternatives and forecasting scenarios. Each run records exactly which model version and settings produced it.
  • TDM calibration reports show each calibration iteration. Calibration is tied to a pinned model version so that results can be reproduced.

The calibration dashboard summarizes calibration results by scenario, and the vizTool (source) helps explore model results through maps and charts.

Geography

The analysis zones repository is the source of truth for the traffic analysis zones (TAZ) the model uses. Each release is a tagged version of the zone layer.
